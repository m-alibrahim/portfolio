More projects are being added.

## Using the templates

- **Client Needs Questionnaire:** open `index.html`, set `NOTIFY_EMAIL` to your address, then replace `YOUR FIRM` / `CLIENT CO.` and the questions. Responses are sent through FormSubmit; the first submission asks you to confirm your email.
- **Candidate Evaluation:** works offline. Data is stored in the browser's localStorage. Connect your own backend (with authentication) before using it with real candidate data.
