The problem

Preparing a tender proposal takes days of reading, copying and formatting, and one missed requirement can sink the bid. Other repeat jobs, like opening a new client file or redacting a document before sharing it, get done from scratch every time.

How it works

  1. The proposal skill reads the booklet, pulls out requirements and scoring criteria, and builds the compliance matrix and pricing.
  2. It produces a Word file and a deck in Arabic, in the bidder's own branding.
  3. Two supporting skills: turning first-call notes into a client file, and permanently redacting names and amounts in PDFs.

Try it yourself

Open the files and read each skill's instructions. They can be installed in Claude and tried on a real tender booklet.

The skills are published with no firm or client data.
