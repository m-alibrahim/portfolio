Client intake file

Turns notes from a first client call into an organised file the client completes: a summary, open questions and a document checklist.

Try the demo

The problem

After the first call, the lawyer spends days chasing the client for missing details and documents, one message at a time.

How it works

  1. The lawyer pastes the call notes as written, unsorted.
  2. The tool prepares a summary for the client to correct, specific questions and a document list.
  3. It also drafts the WhatsApp message to send with it.

Press the ready-made example button to see a full file built from a fictional call. The demo interface is in Arabic.
