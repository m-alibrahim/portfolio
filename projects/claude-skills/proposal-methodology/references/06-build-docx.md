# بناء ملف وورد عربي

استخدم `scripts/docx_builder.py` مباشرة. يغطي كل ما يلي جاهزا.

## الاتجاه
python-docx لا يضبط الاتجاه تلقائيا. المطلوب في ثلاثة مستويات معا، وإهمال أي منها يكسر الملف:

1. **الفقرة**: `<w:bidi/>` داخل `pPr` ومحاذاة لليمين.
2. **الـ run**: `<w:rtl w:val="1"/>` داخل `rPr`.
3. **الجدول**: `<w:bidiVisual/>` داخل `tblPr` حتى يبدأ العمود الأول من اليمين.
4. **القسم**: `<w:bidi/>` داخل `sectPr`.

## الخط
اضبط `w:rFonts` على السمات الأربع معا: `w:ascii` و`w:hAnsi` و`w:cs` و`w:eastAsia`. ضبط `w:cs` وحده لا يكفي.

أضف `w:szCs` بنفس قيمة `w:sz`، وإلا بقي حجم النص العربي على الافتراضي بغض النظر عن `font.size`.

للنص العريض أضف `<w:bCs/>` إلى جانب `b`.

## البنية
- الغلاف: اسم الكيان، ترخيصه، عنوان العرض، اسم الجهة، ثم جدول بيانات مقدم العرض. ثم فاصل صفحة.
- عنوان رئيسي: حجم 16، غامق، باللون الأساسي، بحد سفلي باللون الثانوي.
- عنوان فرعي: حجم 12.5، غامق، باللون الثانوي.
- نص: حجم 11، تباعد أسطر 1.35، محاذاة ضبط.
- رأس الجدول: خلفية باللون الأساسي ونص أبيض غامق.
- صف المجموع: خلفية باللون الفاتح ونص غامق باللون الأساسي.
- فاصل صفحة قبل الأقسام الكبرى: المنهجية، الجدول الزمني، العرض المالي.

## قبل التسليم
```
bash scripts/render.sh out.docx
```
افحص خصوصا: انعكاس أعمدة الجداول، وقص النص في الخلايا، وتسلسل ترقيم الأقسام بعد أي حذف.
