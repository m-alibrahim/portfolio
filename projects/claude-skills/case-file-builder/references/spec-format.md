# صيغة ملف spec.json

ملف وصف يقرأه `scripts/build_case_file.js` ويحوّله إلى وورد عربي مضبوط الاتجاه.

## الهيكل الأعلى

```json
{
  "org": "شركة المكتب",
  "title": "ملف القضية",
  "subtitle": "وصف موجز للنزاع",
  "internal": false,
  "footer": "ملف القضية — اسم العميل",
  "meta": [["العميل", "..."], ["الطرف الآخر", "..."]],
  "intro": ["الأستاذ / ... المحترم", "السلام عليكم ورحمة الله وبركاته، وبعد"],
  "sections": [
    { "h": "عنوان القسم", "blocks": [ ] }
  ]
}
```

- `internal: true` يضيف شريط "مذكرة داخلية — لا تُسلّم للعميل" تحت العنوان. يُستخدم في ملف الفريق فقط.
- `meta` جدول تعريف من عمودين.
- `intro` أسطر المخاطبة قبل أول قسم.

## أنواع الكتل

| النوع | الاستخدام | الحقول |
|---|---|---|
| `h2` | عنوان فرعي داخل قسم | `text` |
| `p` | فقرة | `text` |
| `note` | فقرة داخل إطار رمادي (تنبيه أو تمهيد مهم) | `text` |
| `bullets` | نقاط بشرطة | `items[]` |
| `numbered` | نقاط مرقمة | `items[]` |
| `fill` | سطر تعبئة بعنوان يمينه ونقاط | `label` |
| `lines` | أسطر تعبئة فارغة | `n` |
| `question` | سؤال مرقم تحته أسطر تعبئة | `text`, `lines` |
| `kv` | جدول عمودين معبأ | `rows[[k,v]]`, `widths` |
| `form` | جدول عمودين: بيان / تعبئة فارغة | `items[]`, `headers`, `widths` |
| `table` | جدول عام | `headers[]`, `widths[]`, `rows[[..]]`, `emptyRows`, `numbered`, `totalRow` |
| `signature` | خانة الاسم والتوقيع والتاريخ | `labels`, `widths` |
| `spacer` | فراغ | `after` |

## أعراض الأعمدة

مجموع `widths` يجب أن يساوي 9000. إن اختلف يعيد السكربت التوزيع تلقائيا، لكن الأفضل ضبطه يدويا.

قيم مجربة:

- جدول عمودين: `[3600, 5400]` أو `[2600, 6400]`
- جدول تسلسل زمني: `[1400, 5200, 2400]`
- جدول مستندات: `[560, 4400, 2600, 1440]` — م، المستند، لماذا نحتاجه، متوفر؟

**تحذير من تجربة سابقة:** عمود الترقيم لا ينزل عن 520 وإلا التف الرقم 10 على سطرين. وعمود يحوي مبلغا مثل 10,000,000 لا ينزل عن 1400.

## مثال مختصر

```json
{
  "title": "ملف القضية",
  "subtitle": "مطالبة مالية عن أعمال منفذة",
  "meta": [["العميل", "..."], ["تاريخ المكالمة", "..."]],
  "sections": [
    {
      "h": "ما فهمناه من مكالمتنا",
      "blocks": [
        { "t": "note", "text": "هذا ملخص ما وصلنا من مكالمتنا. صححوا ما هو غير دقيق." },
        { "t": "numbered", "items": ["...", "..."] }
      ]
    },
    {
      "h": "قصتي",
      "blocks": [
        { "t": "note", "text": "هذه المساحة لكم وحدكم..." },
        { "t": "lines", "n": 10 }
      ]
    },
    {
      "h": "المستندات",
      "blocks": [
        { "t": "h2", "text": "نحتاجها الآن" },
        {
          "t": "table",
          "headers": ["م", "المستند", "لماذا نحتاجه", "متوفر؟"],
          "widths": [560, 4400, 2600, 1440],
          "numbered": true,
          "rows": [["1", "العقد", "لنعرف ما التزم به كل طرف", ""]]
        }
      ]
    }
  ]
}
```
